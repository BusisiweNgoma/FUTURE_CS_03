# FUTURE_CS_03
Read-only API security assessment using OWASP principles and postman to identify data exposure, authentication gaps and access control risks.

this project focuses on analyzing public endpoints to identify potential security risks using safe, read-only testing methods. the goal was to understand how exposed data, weak authentication, and access control issues can appera in real world API enviroments.

the assessmetn was conducted using publickly available APIs and followed OWASP API security principles to observe responses, inspect returened data, and document possible risks.
